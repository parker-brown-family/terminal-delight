01.1Install

TERMBENCH

Terminal Delight ships as one file, terminal-delight-x86_64.AppImage, for 64-bit Linux on X11 or Wayland. Download it, make it executable, and run it.

Three commands
curl -LO https://github.com/parker-brown-family/terminal-delight/releases/latest/download/terminal-delight-x86_64.AppImage
chmod +x terminal-delight-x86_64.AppImage
./terminal-delight-x86_64.AppImage

The rest of these docs call it terminal-delight. To get that command, move the file into a folder on your PATH under that name.

mv terminal-delight-x86_64.AppImage ~/.local/bin/terminal-delight

Nothing is installed system-wide. It runs from wherever you put it, uses your system's graphics driver like any other native app, and keeps its settings in ~/.config/terminal-delight/.

TERMBENCH

Terminal Delight is built on gpui, the UI framework from the Zed editor, and it needs a gpui that crates.io does not have. That one fact decides how it is distributed: a prebuilt AppImage for running it, and a build against a pinned Zed checkout for changing it.

01.1.1What it needs#

A 64-bit x86 machine, X11 or Wayland, and a working graphics driver, taken from your system. The renderer is wgpu, which targets NVIDIA, AMD and Intel, and the app reports the GPU and driver it found when it starts.

Wider testing on AMD, Intel, Wayland and fractional scaling is open work for 1.0, and so is a Flatpak.

Architecturex86_64, the only asset
DisplayX11 or Wayland
Graphicsa working Vulkan or OpenGL driver
Fontsnothing to install
Soundoptional: ffplay or pw-play for the finish ping

01.1.2The file#

The address in the Brief always redirects to the newest release, so it keeps working after the next one ships. To update, download it again over the old file.

The AppImage passes every argument through to the program, so ctl, mcp, surface and the other subcommands work through it.

01.1.3Building from source#

setup-deps.sh installs Vulkan and the build libraries on Ubuntu. prepare-gpui.sh sets up a sibling zed-upstream/ at Zed commit abbe85a and applies six patches from docs/patches/, starting with the per-pane barrel warp. CI builds the same way.

For a release binary, run cargo build --release in app/; it lands in app/target/release/terminal-delight.

bash scripts/setup-deps.sh
bash scripts/prepare-gpui.sh
cd app && cargo run

01.1.4Why there is no cargo install#

The crate is not on crates.io, and it cannot be published as it stands. app/Cargo.toml sets publish = false, and gpui is a path dependency on the pinned Zed checkout. The gpui on crates.io ships an older renderer, blade, with known problems on NVIDIA under X11.

01.1.5Where things are kept#

~/.config/terminal-delight/theme.tomlYour own theme, picked up while the app runs.
~/.config/terminal-delight/skin.tomlA skin for the chrome. $TD_SKIN does the same.
~/.config/terminal-delight/launch.tomlWhat a new agent opens with.
~/.config/terminal-delight/notifications.tomlWhat a finished agent may do to the rest of the desktop.
~/.config/terminal-delight/sessions/One file per session: its layout, each pane's directory, and each agent's resume command.
~/.config/terminal-delight/plugins/Plugins, one folder each with a plugin.json.
~/.local/state/terminal-delight/The workbench's surfaces and conversations.

$XDG_CONFIG_HOME and $XDG_STATE_HOME replace ~/.config and ~/.local/state when they are set. Config files lists every file.

01.1.6Agent hooks#

For an agent's replies to reach the workbench on their own, Claude Code needs Terminal Delight's hooks. The installer lives in the source tree, not in the AppImage. It adds td-agent-hooks to ~/.claude/settings.json on five events, keeps a backup of the file, and changes nothing if run twice.

scripts/install-agent-hooks.sh

01.1.7Removing it#

Delete the AppImage, or ~/.local/bin/terminal-delight if you moved it there. Deleting the two folders removes your settings, sessions and saved work. If you installed the hooks, uninstall them from the source tree.

rm -f ~/.local/bin/terminal-delight
rm -rf ~/.config/terminal-delight ~/.local/state/terminal-delight
scripts/install-agent-hooks.sh --uninstall

01.1.8What would prove this wrong#

The three commands should give you a working Terminal Delight on a 64-bit Linux desktop with a working graphics driver. If they don't, that is a bug: open an issue with your distribution, your GPU, and the lines the app prints when it starts.
