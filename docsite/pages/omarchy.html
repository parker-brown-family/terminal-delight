On Omarchy, Terminal Delight can be the terminal the desktop opens. From a checkout of the repository, run scripts/install-desktop.sh, then terminal-delight default-terminal on. Super+Return and Omarchy's TUI launchers then open in Terminal Delight, and terminal-delight default-terminal off puts back the terminal you had.

It already wears your desktop. Every Omarchy theme on the machine is in its theme pickers, drawn in its own colours, and the INHERIT switch keeps the window in step when you change the desktop theme.

Three desktop keys take one step each. scripts/install-keys-hotkey.sh binds Super+Alt+T to a searchable list of every Terminal Delight key. A line in bindings.lua binds Super+Alt+P to the paint overlay. A line in hyprland.lua makes Super+C and Super+V copy and paste in a pane instead of interrupting it.

Technical has the commands, what each one writes, how to undo it, moving an open terminal across with td-send, and the two sibling repos.

The default terminal

Omarchy opens every terminal through xdg-terminal-exec: Super+Return, its TUI launchers, and the agents its Local AI plugin starts. Which terminal answers is one file, ~/.config/xdg-terminals.list.1 Two steps make it Terminal Delight:

# from a checkout of the terminal-delight repository
bash scripts/install-desktop.sh
terminal-delight default-terminal on

install-desktop.sh puts the desktop entry in ~/.local/share/applications/terminal-delight.desktop and the icon in ~/.local/share/icons/hicolor/, as an SVG and, when rsvg-convert is installed, as 48, 64, 128 and 256 pixel PNGs. The entry runs terminal-delight, so that command has to be on your PATH: Install shows the move.2

on refuses until that entry is installed and carries the four keys xdg-terminal-exec reads. Then it writes a journal of what the list held, including "there was no list", to ~/.local/state/terminal-delight/default-terminal.journal, and rewrites the list with terminal-delight.desktop first and every entry that was there after it. It writes nothing else.

CommandWhat it does
terminal-delight default-terminal onSays which terminal it replaced, for example Terminal Delight is now the default terminal; it was foot.desktop., or that there was no list.
terminal-delight default-terminal offPuts the list back byte for byte, or removes it if there was none, and says Put back: the default terminal is foot.desktop again. If the list changed after on wrote it, by omarchy default terminal or by hand, it leaves the newer choice alone and says so.
terminal-delight default-terminal statusFour lines: the default terminal, whether it is Terminal Delight, the desktop entry it found, and the journal.

A terminal opened this way is a quick window. It takes the four flags foot takes (--app-id=, --title=, --working-directory= and -e), runs the program after -e directly in that directory, and never claims a session or starts a session host, so it can't disturb the window you work in. Super+Return therefore gives you a fresh window with a shell; your session opens when you start terminal-delight itself. A pane the Local AI plugin opens wears a LOCAL MODEL mark.3

scripts/install-desktop.sh --uninstall removes the entry and icons it installed, if they're unchanged. 0.5.0's Uninstall runs default-terminal off for you before it removes anything.

Themes

The painter, from 🎨 at the bottom right, shows one tile per Omarchy theme, drawn in that theme's colours. The list is the one Omarchy's own picker shows, hidden themes left out, and it is re-read twice a second, so a theme you install, remove, edit or hide appears in the painter within a second. A theme that ships only an alacritty.toml loads too. On a machine without Omarchy, the stock Omarchy themes come from a copy Terminal Delight carries. The paint overlay's shelves are FAVOURITES and OMARCHY THEMES.4

INHERIT, under RULES in the window's painter, follows Omarchy's selected theme. Every 300 ms it reads ~/.local/state/omarchy/current/theme/colors.toml (~/.config/omarchy/current/ on older installs), and when the desktop theme changes it repaints the window and every pane that follows the window. Painting a theme or picking a colour by hand turns it off, and turning it off brings back the colours you had set. If the file goes missing or can't be read, the window keeps the last colours it read and the switch says INHERIT · unavailable. A pane's own painter has no INHERIT; a pane follows the window or wears its own theme. Themes has the rest.

A new window has INHERIT on. The TERMINIMALIST skin draws flat, square chrome in the selected Omarchy palette; see Skins.

The key sheet: Super+Alt+T

bash scripts/install-keys-hotkey.sh

The installer puts td-keybindings in ~/.local/bin, copies this site's Keys page to ~/.local/share/terminal-delight/keys.html, prints how many keys it read, and adds this line between marker comments in ~/.config/hypr/bindings.lua, with the script's full path, then reloads Hyprland:

o.bind("SUPER + ALT + T", "Terminal Delight keybindings", "/home/you/.local/bin/td-keybindings")

Super+Alt+T then opens Omarchy's searchable key menu, the one Super+K opens for Omarchy's keys, with one line per row of the Keys page's tables, led by the heading it sits under. The sheet reads the copy, so run the installer again after the Keys page changes. HYPR_BINDINGS, DEST and DATA move the three files.5

CommandWhat it does
td-keybindingsOpens the menu, 960 pixels wide and 40% of the focused monitor's height.
td-keybindings --printPrints the lines instead. --page <file> or TD_KEYS_PAGE reads another copy of the page.
scripts/install-keys-hotkey.sh --uninstallTakes the binding out of bindings.lua, removes the script and the page copy, and reloads Hyprland.

That chord used to belong to td-send. If bindings.lua still has a block between -- >>> td-send hotkey >>> and -- <<< td-send hotkey <<<, the installer removes it and prints took SUPER+ALT+T back from the retired td-send hotkey.

The 0.5.0 installer leaves a legacy td-send block where it is, installs nothing, prints Legacy td-send block retained. No files installed. with the steps to remove it by hand, and asks you to run it again.

The paint overlay: Super+Alt+P

terminal-delight ctl paint toggle raises the paint overlay in every Terminal Delight window on the active workspace, and folds them all on the next run. It finds those windows through Hyprland's own socket, so it needs no plugin and no hyprctl. Terminal Delight doesn't bind it for you; add a line like this to ~/.config/hypr/bindings.lua:6

o.bind("SUPER + ALT + P", "Paint terminals", "terminal-delight ctl paint toggle")

The overlay's keys are on Keys.

Super+C and Super+V

Omarchy's universal copy and paste send Ctrl+Insert and Shift+Insert to a window it has tagged as a terminal, and Ctrl+C and Ctrl+V to any other. Terminal Delight takes the first pair as copy and paste. Omarchy's own list doesn't name Terminal Delight, so add this line to ~/.config/hypr/hyprland.lua:7

o.window("terminal-delight", { tag = "+terminal" })

Without it, Super+C reaches the pane as Ctrl+C and interrupts whatever runs there, and Super+V types ^V. Ctrl+Shift+C and Ctrl+Shift+V work either way.

Moving a terminal across: td-send

scripts/td-send, run by hand from a checkout, moves the focused terminal tile into a Terminal Delight pane. It takes foot, Alacritty, kitty, Ghostty and Omarchy's own org.omarchy.* windows.8

In the tileWhat happens
an idle shellA pane opens at the same directory, and the tile closes after Terminal Delight has taken it.
claude or codexThe tile closes first, so the conversation never runs twice, then a pane resumes it by session id.
tmux attach, tmux new -AThe tile closes, then a pane runs the attach again.
anything elseRefused with a notification. Nothing is closed.

The pane goes to a Terminal Delight window on the active workspace, else any window, else a new one. If Terminal Delight refuses after the tile has closed, the session reopens in a fallback terminal, so it always lands somewhere you can see. --dry-run prints the plan as JSON and changes nothing; --address <0xhex> picks a tile other than the focused one; TD_BIN names the binary when terminal-delight isn't on PATH.

scripts/td-send --dry-run

The sibling repos

Two more repositories carry the desktop half, and each works without the other.

  • omarchy-terminal-delight-theme is an ordinary Omarchy theme in Terminal Delight's own colours, phosphor green on black, with no code in it. omarchy theme install with the repository's address installs it.
  • omarchy-terminal-delight-tools holds what a theme can't: a compositor curve that bows every window like a tube, eleven palettes, and td-tint. td-tint writes a palette down another terminal's tty as OSC colours and sets that window's border to match, so foot, Alacritty, kitty and Ghostty can each wear their own colours. td-tint cherry paints the terminal you type it in, and td-tint --theme osaka-jade paints it in an Omarchy theme. The curve is still in development; its README says what to expect.

What would prove this wrong

default-terminal off after on should leave ~/.config/xdg-terminals.list byte for byte as it was, or absent if it was absent. A list that comes back different, with nobody having changed it in between, is a bug in the journal.
