terminal-delight with nothing after it opens a window and restores your session. Give it a directory and the first terminal starts there. Everything else is a verb that does one job and exits without opening a window.

The ones you're likely to type are ctl, to script a running window, and mcp, the relay you register with an agent. surface puts work on your pane's workbench from a script, and probe and bindings say what Terminal Delight would resume and which conversation each agent is in. A word it doesn't know is refused with the usage text, rather than opening a window.

An unknown word prints terminal-delight: unknown command `<word>` and the usage text, and exits 2. An unknown option does the same with unrecognised option. Commands that print can be piped into head without an error.

probe

Keys: shell_pid, fg_pid, kind, comm, cwd, cmdline, resume. resume is the command Terminal Delight would type to bring the agent back, such as claude --resume <id>.

bindings

{"panes": […]}, one row per agent: shell_pid, agent_pid, mode, cwd, session, bond, certain, and the conversation's lineage. bond is how the binding was found: declared (the agent said so), birth (a transcript started with it), sole (the only conversation in its directory) or guess.

Environment the usage text names

TD_SCRATCH=1 opens a throwaway window; TD_SEED_CWD=<dir> and TD_SEED_RESUME=<cmd> seed its first pane. The rest are in Environment flags.
