terminal-delight with nothing after it opens a window and restores your session. Every other word is a verb that does one job, prints its answer and exits without opening a window.

The ones you're likely to type are ctl, which scripts a running window, mcp, the relay you register with an agent, and default-terminal on, which makes Terminal Delight the terminal Omarchy opens. surface puts work on your pane's workbench from a script, skin prints a skin to start your own from, and probe and bindings say what Terminal Delight would resume and which conversation each agent is in.

A word it doesn't know is refused with the usage text and exit status 2, so a typo never leaves a stray window or session behind.

Technical lists every verb, its flags and its exit codes, and the four 0.5.0 adds.

Opening a window

CommandDoes
terminal-delightOpen a window and restore this workspace's session.
terminal-delight <dir>Open a window whose first terminal starts in <dir>. This works only without the session host (TD_NO_SESSIOND=1) and with no saved layout to restore. With the session host, the default, the directory is ignored (issue 798).
terminal-delight [--app-id=<id>] [--title=<t>] [--working-directory=<dir>] [-e <program> [args…]]Open a quick window the way xdg-terminal-exec asks. -e runs the program directly, never through a shell, and the window closes when it ends. Everything after -e belongs to the program. A quick window never claims or saves a session. Anything else in this form is refused: `…` is not one of the launch options (--app-id=, --title=, --working-directory=, -e).

The environment variables that shape a launch, such as TD_SCRATCH and TD_SEED_CWD, are in Environment flags.1

An unknown word prints terminal-delight: unknown command `<word>` and the usage text, and exits 2. An unknown option does the same with unrecognised option. A word that names an existing directory opens a window there, as above. Commands that print can be piped into head without an error.1

probe

Keys: shell_pid, fg_pid, kind, comm, cwd, cmdline, resume. resume is the command Terminal Delight would type to bring the agent back, such as claude --resume <id>.

bindings

{"panes": […]}, one row per agent: shell_pid, agent_pid, mode, cwd, session, bond, certain, and the conversation's lineage. bond is how the binding was found: declared (the agent said so), birth (a transcript started with it), sole (the only conversation in its directory) or guess.

What would prove this wrong

A word the binary dispatches that is missing here. Every verb lives in one roster, VERBS in main.rs, and the dispatcher reads only that list, so the roster and this page should name the same words.

  1. The verb roster, usage text, launch options and exits: main.rs (VERBS, USAGE, parse_contract, dispatch); each verb's own flags: ctl.rs, defaultterm.rs, surfacefeed.rs, briefhook.rs, skin.rs, benchstore.rs, usage.rs, vitals.rs, host.rs.
  2. 0.5.0: the roster in main.rs; restricted.rs, uiconfig.rs, uninstall.rs and its uninstall/export.rs and uninstall/builds.rs.
