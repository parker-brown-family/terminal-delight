A new window opens in the Clean design: flat glass, letters with no glow, nearly square corners, tabs across the top, and very little chrome. Everything Clean puts away is still one click from the CONFIG ▾ button in the bottom-right corner.

What a window shows is yours to choose. Click 🎨, or CONFIG ▾ then UI CONFIG…, and the painter's fourth area lists every piece of chrome as a switch. OUTER covers the frame around the panes: the corner's glyphs, the app mark, the Git notice, the agent counter, the left bar. PANES is one set of switches for every pane's header at once. Hide a corner glyph and CONFIG ▾ takes the corner, listing what the glyphs opened.

Three sets come built in, all, clean and standard, and a design only asks for one: any switch you flip yourself wins. Each design remembers the switches you set while wearing it, and use this window makes the window you're in the starting point for new ones.

Technical has every switch, the three sets, the CONFIG menu and the Clean design.

The Clean design

Clean is the first tile of the DESIGN row, ○ clean, and what a new window wears. Every effect in its file is zero, and while it is worn the tube and the light are held off whatever the GAUGES dials say: the curve, the rolling band, the glare, letter glow, the linger fades and the halos on lit borders. The dials keep their values for the next design you pick. It replaced Quiet, and a window saved on Quiet opens as Clean.1

Clean asks for the clean skin, nearly square (corners of 2 and 3 pixels, never more than 3) and flat with no glow, and for the Clean UI set below. Both are asks: a skin you picked, or a switch you flipped, outranks them. Its own colours show only where no theme is painted; they are the Terminal Delight palette's. With an open-furniture skin such as TERMINIMALIST, side-by-side panes meet on one shared hairline instead of a dark gutter, and dragging the rule still resizes them.

Where it is

UI CONFIG is an area of the window's painter, opened from 🎨 in the corner, or from Surfaces or UI CONFIG… in the corner's menu. A pane's painter (Ctrl+Shift+D) has none, the way it has no SKIN row: one config serves every pane.2

The area opens with two pages, OUTER and PANES, and · yours beside them once any switch has been flipped by hand. Under them is the set row: ◎ design follows whatever the design asks for, then one tile per set, built-in and yours. Under a skin with open furniture the first tile reads skin, because the skin is what's asking. Picking a set asks for that set whole, so it clears every switch you flipped.

Who decides

  1. A switch you flipped in UI CONFIG.
  2. The set: one you picked, else the one the skin asks for, else the one the design asks for, else standard.
  3. Nothing said: shown.

A set names only what it has an opinion on, and a key it leaves out is shown. A set name with no file behind it falls back to all, never to everything off. The window's choice is saved with its session as [ui].2

Your own sets live in ~/.config/terminal-delight/ui/*.toml, named by file, with name, icon, an [outer] table and a [panes] table of true and false. A built-in name always means the built-in. Unknown keys are reported, never fatal, so a set written for a newer build still loads.

terminal-delight ui --list
terminal-delight ui --template clean > ~/.config/terminal-delight/ui/mine.toml
terminal-delight ui --check ~/.config/terminal-delight/ui/mine.toml

--check prints every switch as shown, hidden or shown (no opinion), and exits 1 if the file names a key no switch answers to. Exit 2 is a usage error or a file that can't be read.

CONFIG

Hide any corner glyph, the counts, the scale or the split buttons, and CONFIG ▾ takes the corner. Its menu lists the window's surfaces: THRESHING FLOOR, Surfaces, Sliders, Session restore, Notifications, Agents, Report a bug, ADMIN, Plugins and Artifacts. Then comes one row for each thing hidden elsewhere: the Git notice, Allowance… (also while the left bar is closed), Scale · 100%, and split → and split ↓. UI CONFIG… and HELP come last.3

The button carries what the hidden pieces would have said. With the Git notice hidden it takes the notice's red or yellow; with 🐞 hidden after a crash it takes the crash dot; with 📜 hidden it takes the dot that says an agent handed something over, and so does its Artifacts row.

With the app mark, the Git notice and the agent counter all hidden, the left bar open and no window buttons of its own, the top bar has nothing left to hold. It folds to a 1 px hairline, so the panes sit under the frame by the same margin as down the sides.

Looks that remember

Each design remembers the UI CONFIG choice you made while wearing it, along with its look dials: the set you picked and the switches you flipped. Pick Clean, show the left bar, try Hacker, and Clean has its left bar when you come back. A right-click on a design offers to reset it to as designed, or to undo the last switch or reset. See Themes.4

A skin's ask is never saved as your choice, so moving from TERMINIMALIST to another skin puts the design's own set back.

New windows

The NEW WINDOWS row says what a new window will start as: clean, or this look once you've saved one. use this window saves the window you're in (its design and palette, its skin if you picked one, and its UI CONFIG choice) to ~/.config/terminal-delight/new-window.toml. A clean button then appears beside it; it deletes the file, and new windows open Clean again. A file that won't parse is reported and ignored.2

What would prove this wrong

Turn every switch off and pick clean. If anything UI CONFIG put away can then not be reached from CONFIG ▾, a pane's ⋯ or UI CONFIG itself, a switch has removed a feature where it should only have hidden it.
