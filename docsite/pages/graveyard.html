Claude Code and Codex save every conversation to disk. When the terminal an agent was running in goes away (a crash, a reboot, a window you closed), the conversation is still there, just not running. The graveyard lists those.

Click 🪦 in the bottom-right corner of the window, or Session restore in the … menu. Each row says what the conversation was about, where it ran and how long ago. Rows are grouped by project, and the chips across the top narrow them to one. Click one and it resumes in a new tab, in its own directory, where it left off.

Something you closed a minute ago is probably in the bay instead, still running: Ctrl+Shift+Z brings it back.

Technical has what counts as dead and what a row shows.

What's listed

Every saved conversation that isn't the one any open agent pane would resume:1

  • Claude Code: ~/.claude/projects/<project>/<id>.jsonl
  • Codex: ~/.codex/sessions/**/rollout-*.jsonl

Newest first, up to 80 each time it opens. Ids that aren't plain letters, digits, - and _ are left out, since they would be typed into a shell. The graveyard only reads these files; it never changes one.

A sleeping agent's conversation also counts as live, so it isn't offered here: resurrecting it would put a second agent on the conversation when the first one wakes. Resting agents has how an agent comes to be asleep.3

The panel

The header reads 🪦 DEAD AGENTS, then the split by program (12 claude · 3 codex), the card-size slider it shares with the agent wall, and <n> recoverable. That count is conversations found here; the same words on the bay count what's held there. Under it: click a row to resurrect it — or ⬇ .cdx to harvest its context into a portable package. Chips filter by project: ALL, then one per directory name, each with its count. Rows are grouped by project with <n> dead on each group.2

A row's title is the conversation's own summary, or failing that its first message, cut to 96 characters; with neither, CLAUDE session or CODEX session. Under it:

~/project  ·  3h ago  ·  7f3a91c2  ·  412 KB

Directory, age (s, m, h or d, one unit), the first eight characters of the conversation id, and size. With nothing to list: No recoverable agents — every saved session is either live or already gone. Click outside to close.

The 🪦 is one of the corner's glyphs that UI CONFIG can put away, under MENU GLYPHS. The Clean and Standard designs start with it hidden. Session restore stays in the … menu either way.3

Resurrect

Clicking a row, or its RESURRECT ⏎, opens a new tab in the row's directory, in the branch of the left bar you're in, and types claude --resume <id> or codex resume <id>. If the session is already running that conversation somewhere, it isn't started twice; you're shown that pane instead.2

Harvest

When context-delight's cdx-mcp is on the machine, installed as a plugin or found on your PATH, in ~/.local/bin or in ~/.cargo/bin, each row also has ⬇ .cdx. It packs the conversation into ~/.local/share/context-delight/<id>.cdx, and the result is reported under the header.4

What would prove this wrong

If a conversation that an open pane is running ever shows up here, the live check above has failed, and resurrecting it would start a second agent on the same conversation.
