Recommendation: yes, and build the pushed notice next.

3 · Keep the press limit at 400,000 tokens?

Today’s median Claude pane holds about 360,000, so most copies of a median agent would run without asking you. Each one re-reads that context, and an Opus copy’s cost was not measured. At 0, every copy asks you first.

Recommendation: make 0 the default, so every copy asks you, until the record shows how often agents want copies. It is one constant, and the window has no control for it yet.

Method and limits

what this page is and is not

  • The gates are fmt, clippy with warnings as errors, and the full test suite: 2,776 tests pass and 17 are ignored. The ignored tests are the earlier 15 plus the two live copies, which run by hand on a version bump.
  • No copy of a real working agent pane has been run. The live copies forked seeded scratch sessions, and the window runs used stand-ins.
  • The 1M-context model name for a copy comes from Claude’s own cost record (claude-opus-5-5[1m]). No copy has yet been started with it.
  • Rail colours and photographs are from one theme. The colours come from the theme’s own ANSI slots, so they change with it.
  • The docs were rewritten to match: the MCP doc, the docsite’s MCP, agent wall and panes pages, the key sheet, the terminal-input security note, and every refusal that pointed at the old robot button.
