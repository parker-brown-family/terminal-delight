01A local choice

The local program owns its model and runtime flags. TD reads its configuration when the panel opens, uses that same snapshot for preview and launch, and hides controls that would make promises about flags it does not understand.

The local launch guide shows a Codex + Ollama example and the argument contract for another interactive agent. A local model and a program that can read files and write the brief still need to be installed.

02Comments come back

The configured command carries an explicit local-agent declaration. TD reads it from the foreground process, so an unfamiliar executable can receive notes while the enclosing shell remains a shell after that program exits.
