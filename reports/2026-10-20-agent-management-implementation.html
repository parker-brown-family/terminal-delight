MCP contract

agent_targets returns exact run identities and unavailable states. agent_capabilities reports native evidence. agent_send returns durable TD confirmation. agent_messages reads receipts and exports. agent_reply records attributed progress, result or verification. agent_cancel confirms cancellation only before dispatch.

Reuse the same UUIDv7 key after a lost response. Different payloads with the same key conflict. A receiver window owns the journal and checks its exposure and writes policy. Forwarding retains the asserted original actor separately from the forwarding window.

No launch, resume, process termination or PTY fallback is available. Native interruption is explicitly unsupported in this implementation.

What is recorded

Each immutable actor snapshot carries its conversation, live process identity, pane and shell identity, native endpoint generation, executable/version observations, separate inference-runtime facts and model facts with provenance. Unknown and uncollected values remain explicit.

Requests preserve their exact text and digest, parent/cause links and deadline. Attempts, native receipts, consumption evidence, peer output, recipient reports and attributed manager resolutions are append-only records. Source timestamps remain separate from observation timestamps.

The first Claude tracer has manager verification without a structured recipient MCP result report. It does not invent the missing report. The Codex export includes the exact correlated native reply declining the task.

Checks and limits

Focused checks cover atomic acceptance failure, immutable records, duplicate/conflicting keys, dispatch crashes, damaged outbox recovery, future/malformed journal records, clock rollback, consumer credit, late receipts, model holds, cancellation and cursor identity. Unix-socket fixtures exercise actual native framing and reject wrong request correlation, unknown versions and mismatched Codex routing.

The application adds read-only MCP capability checks and forwarding checks. Format, production Clippy and workspace tests passed for the default and Alacritty terminal cores. The application unit suites passed 2,475 and 2,422 tests respectively; the new core passed 28 and the new MCP checks passed four in each run. Broader Clippy on the existing app test target encounters previously filed lint debt; the new management crate is checked across all its targets.

Claude support is pinned to the measured 2.1.296 profile. Codex is pinned to the measured 0.163.0 protocol and additionally requires matching tool routing. Provider revision remains unknown where the harness does not expose it. No archive/prune mutation or post-dispatch native cancellation is included.

The temporary experimental window retained the existing host and all 30 saved active pane processes. Later its control path disappeared and a released window replaced it before our restore attempt. The cause and replacing actor were not established. The released executable is active with the same pane processes; no default-install link or release tag was changed.
