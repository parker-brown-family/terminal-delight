Yours to decide

Is "modern" a fourth skin, or does the default move?

The default skin is under a gate — default_skin_reproduces_todays_chrome asserts it equals what main.rs draws. Changing the house look means retiring that gate and accepting that the old chrome is no longer reproducible.

Recommend: a fourth skin, named signal. It is the decision you already made for deco — one skin among several until it has been lived in — and it costs nothing to promote later by changing which id is default.

Does the seam conversion go first, or the skin file?

Writing the file first gives you something to look at in two hours, on the bar, the tabs and the whole workbench. But the tray you select it from stays round, so the first thing you see is the seam.

Recommend: the seam first, same week (#408). The conversion is mechanical and the file is the fun part; doing the fun part first is how the seam survives another month.

Tracked uppercase labels — everywhere, or only region headers?

caps = tracked is one token and it hits every label the skin draws. The reference aesthetic uses it on almost everything; at 9pt with real tracking it can also read as shouting on a row that already has an icon and a count.

Recommend: tracked in signal only, and looked at before it is committed to. It is the change most likely to want a size bump with it — 9pt tracked reads smaller than 9pt sentence case.

Does the gradient lift go, or stay as a skin's choice?

Fourteen linear_gradient sites in main.rs; shine already switches them and console already sets flat. deco inherits gradient — likely by omission rather than by decision.

Recommend: flat in signal, and check whether deco meant to be gradient. An art-deco skin with a 2010s lift on its buttons is the kind of thing that stays wrong for months because nothing fails.

Do the three new theme designs (#404) wait?

They are seeded and ready to drop in. On today's shapes they will land looking like today, and the work will read as spent.

Recommend: hold them until the shapes land, then draw at least one of them against signal rather than against default.

Why these numbers

They are one step off console, which is the closest shipped skin: console's air with a 2px corner instead of a hard square, a glow edge instead of a rail, and inks pulled down to the low-alpha hairlines the reference uses. inferred — nothing here has been rendered; the alphas in particular are the numbers most likely to be wrong on a real GPU pass, because the CRT bloom adds light the CSS mockup does not.

What it does not touch

The overlays and the theme tray, until #408 lands. And the terminal grid itself, which is the theme's business rather than the skin's — a skin has never coloured a cell.

Method and limits

what would prove this wrong

Nothing here was rendered

Every mockup is CSS in this file. The app was not launched, no screenshot was taken, and no monitor was woken — deliberately, because probing a live compositor surfaces toasts in other agents' panes. Font metrics, the warp and the CRT bloom will all change how these rows feel.

The counts are branch-scoped

The checkout this was written from is on spine/instance-identity, which predates the workbench sources entirely — benchdraw.rs does not exist in the working tree. Every number was read from origin/main objects. If main has moved since 8dacd98, re-run the greps before acting.

Invalidation

  • If git grep -cE '\.rounded_(sm|md|lg|full|xl)\(\)' origin/main -- app/src/main.rs returns 0, #408 has landed and the whole ordering argument above is stale — write the skin file first.
  • If the 63 are not all in the overlays and the tray — check by line number against the overlay and tray render functions — then the conversion is larger than a day and the estimate is wrong.
  • If a skin file cannot set caps per-surface and tracked uppercase turns out to be all-or-nothing on a look, the type recommendation needs a code change, not a token.
  • If you look at console on a live session and it already reads modern, then the missing piece is a theme to pair with it rather than a fourth skin, and this brief overstated the work.

What was not investigated

Animation and motion — the reference image is static and so is this brief. Whether the window has a motion vocabulary at all, and whether its absence is part of what reads dated, is unexamined.
