Submitted Comments

Each brief lives in an HTML file on your computer. Terminal Delight now saves your comments into that same file when you submit them.

Submitting a comment saves it into the original HTML before the document can close.

Keep the comment

You submitted a comment, closed the brief, and reopened a file that had never received it. Saving now happens inside submission. Deletions and concurrence stamps use the same path.

Close and reopen

The existing writer reads the current file, merges your annotation, and atomically replaces that file. It preserves other writers’ notes and checks that the page content stayed intact.

If a write fails

The toolbar gives the reason and keeps the pending edit. Closing warns before discarding it. Sending the map never claims that an unsuccessful write reached disk.
