Each of these was mine to decide while building, and each is a small change if you would rather it went the other way.

It carries news, like the attention pill Clean keeps. But so does 🐞, which Clean folds.

Does a pane whose agent has exited keep its card?

Yes, until the pane closes. The card is the way back to that work.

How the pictures were made

A real window nobody could see. The branch's debug build, launched by Hyprland onto a special workspace with no focus change, on a throwaway session (rig-art-*) with its own state directory and stubs for xdg-open. Pictures came from grim -T on that window, and keys from send_shortcut. Nothing reached your session or your desktop: the stubs logged zero launches.

Stand-in agents. A short script named claude, started in each tab by the layout's restore line, prints turns ending in a Deliverable: line, the way Claude Code does. The window reads those lines once a second. The servo stand-in then calls open_document through terminal-delight mcp, the same relay Claude Code uses, while a page is open over its pane.

One mistake, caught and cleaned up. The first two runs named the stand-in as a bare claude. The panes' shell startup put the real Claude Code first on PATH, so five real sessions started in the rig, with tab names as their prompts. They only listed and read files inside the rig folder and the repository, and died with the rig about 45 seconds later. I deleted their transcripts. The rig now names its stand-in by full path, refuses a bare program name, and checks afterwards that no real session ran. None did in the runs that made these pictures.

Mine, not measured. The hop's height (4 px) and length (520 ms), the rail's width, and every label on the stand-in cards. Times on the cards are real, from when the rig ran.
