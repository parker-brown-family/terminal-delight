Read first

  1. What ends the wait is the screen, not a deadline

    What it is. While a dial press is in flight the bench holds every write, and lets go once no menu is on the screen. No timeout fires while one is up.

    Why it matters. A draft typed into a picker is a menu keystroke, and the digits in somebody's sentence are option numbers. That cannot be taken back; waiting can.

    What it would take to change. One arm of dial_step, and a test that says a draft was typed into a menu.

  2. Your test photographed the one screen I had to guess at

    What it is. You pressed the dial mid-prompt on today's main, the confirmation came up, the effort stayed put, and the picture showed the picker carries no esc to cancel — which was the only thing telling this code a menu was up.

    Why it matters. A permission gate drawn the same way read as no menu, so a held draft would have been typed into it. The gutter mark is now a second signal, and the real screen is a test fixture.

    What is still unphotographed. The bench's own surfaces — the table, the artifact card, the YOU block. One command, in the modal at the bottom.

  3. Six spellings for "where the document is"

    What it is. href, open, path, file, url, link — in that order of preference, local file before served URL.

    Why it matters. This is a protocol widening. Every spelling added here is one more thing the window promises to keep understanding.

    What it would take. Deleting a string from a six-element array.

  4. The demo now seeds the payloads that break

    What it is. The demo's artifact used the one spelling that always worked and its table had two-word cells, so the screen people look at on purpose could not show either defect.

    Why it matters. That fixture is why two of today's five survived. It is now the shape that arrives on real benches.

    What it would take. It is one payload in demo_surfaces(), with a test that fails if it goes back.

  5. If the harness never asks, the draft comes back in 1.5 seconds

    What it is. The only clock left. A harness that applies /effort max outright — Codex, or a level Claude Code does not think is worth asking about — never raises a picker.

    Why it matters. It is the case that makes the hold safe to have at all, and it is the one I could not test against a live harness.

    What it would take. A constant.

Yours to decide

Is the hold right?

A dial press can hold your composer indefinitely if a picker you never answer stays up. My recommendation: keep it. The far end is not reading a sentence from anybody in that state, so nothing is lost by waiting, and the alternative loses a keystroke into a menu.

Six spellings, or fewer?

href · open · path · file · url · link. Every one of them is a word an agent on this box has actually used for a document. My recommendation: keep all six and treat the list as the protocol's real surface, since a refused artifact is silent from the agent's side.

Should an artifact's extra keys be on the card?

Its finding, measured and served are drawn as facts under the target, in the order the agent wrote them. The alternative is dropping them, which is what happened before. My recommendation: drawn.

Want the photographs before this merges?

The pixels are the one leg I could not run. My recommendation: merge, then look — every change is behind a test, the demo now seeds the shapes that break, and the checking command is one line. Say the word and I will stage it the moment your screen is free.

What ends a hold that has no deadline

The menu going away, whoever makes it go — our keypress or your hand. The agent leaving the pane also clears it, because the next agent is a different conversation.

The case this cannot reach

A dial pressed while the pane is off screen. The command is queued rather than written, the hold goes on anyway, and the whole sequence plays out when the pane comes back — which is the existing rule for every bench write and not a new one.
