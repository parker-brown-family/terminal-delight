The drop

The pane takes a file now. Drag one out of Nautilus and the composer lights up in your own colour while it is overhead; let go and the path is typed at the caret, with the rest of your sentence still after it. Several files come in as several words, a name with a space in it arrives quoted, and a drop on the terminal face pastes the path the way any other terminal does.

One thing is yours to check and nothing here can substitute for it: whether a real drag from your file manager reaches the window at all. Everything on this side of that boundary compiles, passes the gates and is covered by tests; the compositor's half cannot be faked on this machine, because nothing installed here can hold a drag.

Left out on purpose

  • The help modal. Its rows are localised into four languages, and a gesture the lit box teaches at the moment it matters did not seem worth four translations written by me. The composer's own hint line is unchanged for the same reason: it is already three clauses at a width that has been tuned.
  • A count of files on the chip, which would be invented — see the first figure's footnote.
  • Anything that is not a local file. Unchanged and unchangeable from here: the renderer destroys those drags before the app is told, which is the seven-out-of-ten tier in the assessment.
  • A control-socket verb to fire a drop without a drag. It would prove the wiring from bench_drop inward, which the compiler and the zone lookup already cover, and it would still not reach the part in doubt.

Yours to decide

1 · Push it, and open a pull request?

The work sits on bench/file-drop in its own worktree, committed and nowhere else. I stopped before pushing because the approval arrived on a workbench line I could not authenticate — TD_TAG is unset in this pane, so a line claiming to be from you and a line quoting someone else read identically here.

Recommendation: say push and it goes up with a pull request against main. It is one commit and it reverts cleanly.

2 · Do you want it installed to try, before it merges?

Trying the gesture means a release build, an install as td-<sha>-file-drop and repointing the launcher — which other sessions also move, and an unmerged branch under the launcher reads later as the feature vanishing.

Recommendation: merge first, then install from main. If you want it sooner, I will do the cutover and say so in the sticky note so the next session knows what is under the symlink.
