Terminal Delight — live demo run-of-show

15 September 2026 · YouTube live · OBS profile Terminal Delight · capture eDP-1 2560×1600 @ 60

Before you hit Start Streaming

The stream key is the only thing missing. YouTube Studio → your live event → Stream key (copy). In OBS: Settings → Stream → Service Custom, Server is already rtmp://a.rtmp.youtube.com/live2 — paste the key, OK.
  • OBS lives on DP-2 (the external). The capture is eDP-1, so OBS itself never appears in shot. Keep it that way.
  • Mic is the Shure MV7 (mono). Talk and watch the meter move before you go live.
  • Desktop audio is the MV7's own output monitor — the agent-finished bell will be audible to viewers. That's usually what you want.
  • Webcam C920 on /dev/video2, 1920×1080 MJPG 30 fps.
  • Encoder NVENC H.264, CBR 12 000 kbps, 2 s keyframes, preset p5. If the OBS status bar starts counting dropped frames, drop to 8 000 and carry on — don't stop the stream.
  • 16:10 canvas. YouTube's player is 16:9, so viewers get thin bars top and bottom. Expected, not a fault.
  • Legibility. A 2560-wide capture gets scaled down in most viewers' players. Bump TD's text size in the monitor-OSD tray before the cold open — one notch bigger than feels right to you.
  • Staged content only. Throwaway home, fake prompt, no real shell — same rule the screenshots follow.

The demo — eleven beats

Green beats are the spine; amber ones are the first to cut if you're running long.

1

Cold open — the wallcore

Open on the twenty-pane window. Don't type anything for ten seconds. Let them look.

"This is one window. Twenty real shells, every one on its own PTY, every one with its own tube, theme and curvature. Nothing here is a screenshot and nothing here is a mock."

2

It's a real terminal firstcore

Split, run something heavy, resize the pane while it's running.

alt+v          split vertical
alt+h          split horizontal
alt+←  alt+→   move between panes

Then in a fresh pane:

vim
seq 1 100000

"Full VT emulation — vim, top, tmux all behave. That seq takes 0.089 seconds, and key-to-pixel is 121 microseconds at the median. The pretty part is not costing you the terminal."

3

Themes hot-reload — edit it while it runscore

Open the theme file in a pane, change a colour, save. The window repaints in about 300 ms, on camera, with no restart.

vim ~/.config/terminal-delight/theme.toml

"Four themes ship — hacker, tactical-overdrive, field-command, quiet-command. They're TOML data files, which means the contribution path into this project doesn't require writing a line of Rust."

4

Per-pane gradingcuttable

Open the monitor-OSD tray. Change brightness, contrast, colour, warp on one pane. Show the "follow outer" toggle breaking the inheritance.

"Each pane is graded independently, like a monitor rather than a text box. The dials are plain percents, and they're the same dials the MCP server exposes to an agent."

5

Sticky notescore

Press a note onto a pane, write on it, then drag the pane so the note warps with it.

"What this shell is for. What you were half-way through. What to check when you get back. It rides the barrel warp with the pane and it survives a restart — this is the thing I actually use most, and it's the least technically impressive thing in the app."

6

Copy chips — the one-click affordancecore

Hold Alt over a line that starts with a command. Chip appears. Alt+click copies the whole rejoined line even though the terminal wrapped it.

"The terminal wrapped that command across three rows. Copying it out of any other terminal gives you three broken pieces. The chip only appears on a line that actually starts with a command, and never on an elided one — a truncated command that looks copyable is a trap."

7

Agent panes and the tab stripcore

Start an agent in a pane. Collapse to a different tab. Point at the badge under the tab as it breathes, then goes yellow HEY, then ✅.

claude

"You never open a tab to find out whether anything is happening in it. Breathing means working. Yellow HEY outranks everything else on the strip — that one means the turn is yours."

Let a toast fire and click it to zip to the pane.

8

The MCP server — the agent can see the windowcore

In an agent pane, ask it out loud to survey the window. Let the audience watch the answer arrive.

"Every agent in here can list every pane — who's running where, in what directory, and which tool they're calling this second. It can grep the scrollback of all twenty panes at once and tell me which pane the error is in. And it can stick a note on another agent's glass."

"What it cannot do is write a byte to anyone's PTY. That's appearance-only, deliberately."

The grep is the money shot — find one string across twenty panes and land on the pane that has it.

9

FOCUS readercuttable

Alt+R to open the reader over the whole conversation; Esc closes. Type while it's open — input still reaches the agent.

10

td-send — adopt a tile off the desktopcuttable

Focus a foot or Alacritty tile with an agent in it, press SUPER+ALT+T, watch the session migrate into a TD pane and resume by session id.

"Idle shells reopen at their directory, agents resume by session id, tmux re-attaches. Anything it can't safely adopt — vim, htop — it refuses, and nothing gets closed."

If it misbehaves on camera, td-send --dry-run prints the plan and touches nothing.

11

Land itcore

"Linux only, X11 and Wayland. MIT, single AppImage, no install ceremony."

chmod +x terminal-delight-x86_64.AppImage
./terminal-delight-x86_64.AppImage

Put the repo URL on screen and leave it there while you take questions.

https://github.com/parker-brown-family/terminal-delight

If something goes wrong live

  • Dropped frames climbing — Settings → Output → Streaming → bitrate 8000. Don't stop the stream to do it.
  • Screen capture goes black — the pipewire portal session died. Right-click the source → Properties → re-select eDP-1. Talk over it.
  • Mic dead — the MV7 is alsa_input.usb-Shure_Inc_Shure_MV7-00.mono-fallback. Reselect it in the source properties.
  • TD crashes — say so and relaunch it. Layout and per-pane appearance restore on launch, which is itself a feature worth showing.
