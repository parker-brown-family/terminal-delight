# Terminal Delight 0.5.4

Terminal Delight is a GPU-native terminal for Linux, written in Rust, for running many shells and coding agents in one window. 0.5.4 lets the Threshing Floor reach agents on your other machines, lets an agent you promote start a team of agents in visible panes, and gives Settings a filter box.

TD-Host-Restart: recommended

## Highlights

- **Agents across machines.** A window can open another machine's Terminal Delight over ssh, and the Threshing Floor reaches the agents there: an agent here can see, ask and prompt one there, as far as that machine allows. Each machine says how far another may reach into it, in Settings › Environments. A machine not listed reaches nothing.
- **High trust agentic.** Turn it on in Settings › Agents › Sharing & access › Teams, then promote an agent to orchestrator from its card on the Threshing Floor or its pane's right-click menu. That agent may open a tab, start agents in visible panes there and prompt them, up to eight at once. Off, only you start agents.
- **A filter at the top of Settings**, the same box as the help sheet's. Type a word and every page narrows to the rows that match, each with its own switch, so a setting is found and changed in one place. Typing "trust" lands on High trust agentic.
- **Every agent setting is under Agents.** Sharing & access moved there from Connections, beside Providers and Threads.
- **rio-vt 0.5.32.** The terminal core now caps an XTGETTCAP request, stops storing OSC 1337 user variables and ignores an OSC 8 link over 2,047 bytes. Before, a program could make a pane hold memory in proportion to what it sent through those. The six issues from the September advisory (GHSA-gpqv-v5wv-3frf, now published) were already stopped by Terminal Delight's own guards, which stay.

## Upgrading from 0.5.3

Update from ⚙ Settings › Updates, or run `terminal-delight update`. Nothing you saved is renamed or moved.

- **Restart once, the session host included.** The new terminal core runs in the session host, which keeps the core it started with until it restarts. Quit every window, end the host with `pkill -f '[t]erminal-delight.* serve --session'` (or restart the computer), then start Terminal Delight again. Tabs come back and agents are resumed; scrollback is not.
- **Sharing & access** is now listed under Agents in Settings. Its switches are as you left them.
- **Agents across machines** needs 0.5.4 on both machines.

**On a build older than 0.5.0?** It has no updater. Move `~/.local/bin/terminal-delight` aside and run `curl -fsSL https://terminal-delight.brownfamilysports.com/install.sh | sh`.

## Known limits

- The cross-machine Floor has been run with both halves on one computer, in two separate homes, and not yet between two physical machines.
- In a window showing another machine, the launcher still lists this machine's projects, and that machine's workbench, documents and artifacts read as empty.
- Agents on another machine are a section of the Floor, not cards on the org chart or the System Map.
- No Tailscale-specific discovery: a machine is a name ssh can reach.
- A team cannot yet be seen or ended as a team: its tab and org are ordinary. Teams on another machine are not offered.
- The limits in the [0.5.3 notes](v0.5.3.md) still stand.
