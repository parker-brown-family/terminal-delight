# Release notes

One file per version, `vX.Y.Z.md`, shared by that version's candidates. The
publish job in CI refuses a version tag that has no file here, and makes the
file the body of the GitHub release (see [RELEASING.md](../../RELEASING.md)).

Keep each one short: the highlights a user would want to hear about, how to
install or upgrade, and thanks to outside contributors by name. The complete
record of changes is [CHANGELOG.md](../../CHANGELOG.md).
