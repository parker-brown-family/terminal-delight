# Terminal Delight 0.4.0

Terminal Delight is a GPU-native terminal for Linux, written in Rust, for running many shells and coding agents in one window. 0.4.0 is everything that has landed since 0.3.0 on 18 September.

## Highlights

- **Chalk, a paper skin.** Pick Skin → Chalk in the painter's Style area. Controls, menus and gauges become deckled paper with handwritten labels, while the terminal's own text stays monospace. It follows your palette, Terminal Delight's or your Omarchy theme's, light or dark, and sticky notes get a strip of tape and a small flower on the curled corner.
- **A warning when panes change the same files.** One GIT signal covers every project in the window. Alt+G opens an inspector showing which working copies, branches and panes share files, with a sentence saying why each finding is shown.
- **Documents open inside the terminal.** Alt+click a path to a picture, Markdown file, HTML page, PDF, video or sound, and it opens in a floating square beside the line that printed it. Ctrl+Alt+click opens it in a new pane beside the one you clicked.
- **Notes on a document go to the agent next to it.** Decision briefs and Markdown files take notes, pasted pictures included, and **↪ send to agent** puts them in that agent's prompt without pressing Enter.
- **A new terminal core, rio-vt, from the Rio terminal.** An 8 MB stream parses in 82 ms instead of 140, 10,000 lines of history take 11.0 MB instead of 28.5, and programs that speak the Kitty graphics protocol, such as `kitten icat`, draw pictures in the pane.
- **The FOCUS reader (Alt+R) reads an agent's conversation.** On a Claude Code or Codex pane it shows the conversation from its transcript instead of the narrow screen.
- **The workbench talks to Claude Code directly.** On each pane's second face, a question the agent asks arrives whole, your answer goes straight back, and the conversation's history survives a restart.
- **Panes other agents cannot reach.** Right-click a pane and choose **Off-limits to agents** to hide it from every other agent. An agent that needs more access has to ask, and waits for a person's Yes or No.
- **Closer to Omarchy.** Terminal Delight can be the terminal Omarchy opens: install its desktop entry with `scripts/install-desktop.sh` from a source checkout, then run `terminal-delight default-terminal on`; `off` puts the old one back. INHERIT follows the desktop theme, and the colour pickers offer exactly the themes Omarchy's own picker shows.
- **An idle window costs less.** On the laptop it was measured on, an idle one-pane window's GPU memory fell from 182 to 86 MiB, and panes in hidden tabs redraw at most every five seconds.
- **New ways to get around.** Alt+L finds a tab, pane or sticky note by name. Ctrl+Up and Ctrl+Down jump through your own messages in a Claude Code or Codex pane, and Ctrl+= and Ctrl+- size the focused pane.

## Upgrading from 0.3.0

Nothing you saved is renamed or moved. Sessions saved by 0.3.0 load, and a 0.4.0 window attaches to a session host started by 0.3.0.

- **Some keys changed.** Ctrl+Alt+R renames the highlighted left-bar row; Alt+V still splits. Shift+click on a file path reveals it in the file manager, and Ctrl+click opens it. On Omarchy, SUPER+ALT+T opens the list of Terminal Delight's keys instead of sending a tile; `td-send` still works when run by hand.
- **Terminal Delight now takes chords your shell or editor used to get:** Alt+L, Alt+A, Alt+G, Ctrl+= and Ctrl+-, Ctrl+Shift+= and Ctrl+Shift+-, Ctrl+Shift+Alt+arrows, Ctrl+Shift+M, and Ctrl+Up and Ctrl+Down in Claude Code and Codex panes.
- **Some looks change.** Sticky notes take new colours from the theme on the first launch. The Gamba design is gone, and a pane saved on it opens on the custom theme. The Field design is now Tactical: a window or pane saved on Field opens on Tactical, keeping any palette you picked and its dials.
- **The workbench's hooks edit Claude Code's settings.** `scripts/install-agent-hooks.sh` adds five hooks to `~/.claude/settings.json`, keeping a backup, and `--uninstall` takes them out. Without them the workbench types keys, as it did in 0.3.0.
- **Building from source?** Re-run `scripts/prepare-gpui.sh`; the pinned gpui checkout gains two patches.

The changelog's "Upgrading from 0.3.0" section has the full list.

## Fixes

Tabs no longer come back out of their projects after the window restarts, and a window that stops saving its layout now says so. Paths and links that Claude Code or Codex wrap across two rows open whole, and the Alt copy chip works when Claude Code runs fullscreen. A restart reopens the session that was on that workspace, and each pane shows its own agent's conversation instead of a neighbour's. Window shortcuts work while the workbench is showing. The changelog has the rest.

## Security

A paste can no longer end bracketed paste early and type the rest into your shell: every paste loses its control characters except newline, carriage return and tab. HTML pages open with the network off unless you allow it in `documents.toml`. MCP answers that quote other panes are labelled as untrusted terminal data.

## Install

Linux x86_64, one file:

```sh
curl -LO https://github.com/parker-brown-family/terminal-delight/releases/latest/download/terminal-delight-x86_64.AppImage
chmod +x terminal-delight-x86_64.AppImage
./terminal-delight-x86_64.AppImage
```

The download line fetches the newest stable release. Each release now comes out first as a candidate, marked Pre-release, which that line never serves; to try one, download the AppImage from its own release page. Every release attaches the AppImage's SHA-256 as `terminal-delight-x86_64.AppImage.sha256`.

PDFs need poppler, video and sound need libmpv, and HTML pages need Chromium. Each is optional; without it, the file opens in your desktop's own app.
