# Terminal Delight 0.5.0

Terminal Delight is a GPU-native terminal for Linux, written in Rust, for running many shells and coding agents in one window. 0.5.0 is the first stable release since 0.3.0 on 18 September. 0.4.0 stopped at its third candidate and never shipped stable, so everything the 0.4.0 candidates carried is here too, listed after what is new.

TD-Host-Restart: recommended

## Highlights

- **Terminal Delight updates itself.** ⚙ CONFIG › UPDATES, or `terminal-delight update`, finds a newer build on the channel you pick: Stable for published releases, or Dev for the rolling build of the development branch, marked experimental. A download is checked against its published checksum and installed beside the old build. Your settings are backed up first, and **Roll back** is one press away. An update restarts only the window, so your terminals and agents keep running. A build that changes how the window talks to its terminals waits for the next cold start, or ends them only after asking you twice. This is the first build that can update itself, so you install it by hand once.
- **The Threshing Floor decides which agents may reach each other.** The agent counter opens an org chart. Seat agents, draw lines between them, and each line says whether one agent may find, read, ask or prompt another. A pane nobody seated is never asked, and a copy of another agent can only read and waits for your Yes.
- **Panes have names agents can say.** An agent names a pane the way you read it, by its place on the left bar and its header's title. It names another agent by its conversation, which outlasts the pane that agent sleeps and wakes in, and an idle agent is listed as resting or asleep.
- **TERMINIMALIST, a flat skin.** Square furniture in your Omarchy palette, no nested frames or boxes, no border round the outside of the tile, and under Clean a single upright line between side-by-side terminals.
- **Get around without the mouse.** Hold Alt and a digit to mark the pane you are on, and tap it to come back from anywhere. Alt+O opens what the focused pane handed over, and pressed again lists that pane's artifacts, then every pane's, Alt+Q opens the queue of agents waiting on you with numbered rows, Alt+0 goes back through the panes you visited, Shift+PgUp pages any pane's history, Alt+E finds the last error line, and Alt+[ puts a pane in scroll mode, where letters move through its history by line, turn and error. Any tab can be pinned to Alt+Shift and a letter.
- **The help sheet (F1) filters as you type.** Type a word and the sheet narrows to the rows and sections that say it, across shortcuts and features together. It scrolls inside the window, lists every chord in this release, including the keys a document takes while you read it and the keys scroll mode takes, and its FEATURES tour is rewritten for 0.5.0.
- **Ctrl+C in an agent's prompt keeps what it clears.** In a Claude Code or Codex pane, the words Ctrl+C is about to clear go to the clipboard first, with any screenshots you pasted given back as their files, so one stray finger no longer loses a long prompt.
- **More light where you are working.** ACTIVE TERMINALS gains a brightness gauge for the focused pane, and the cursor can leave a phosphor trail, off until you turn it on.
- **First launch opens in Clean.** The other designs use Ops trim with smoked glass, and each design remembers your later changes.
- **Briefs an agent hands you take notes and judgement calls.** Every heading, figure and decision of a brief takes a note, and a decision the agent had to make because nobody else had arrives as a row you stamp or overturn.
- **A page or Markdown file you open is opened to read.** It fills a centred reading frame, and while you read, the keyboard is the document's: j and k scroll, Tab walks the sections and decisions, Enter writes a note, c stamps a decision, and Ctrl+Shift+Enter sends your notes to the agent. Nothing you type reaches the shell underneath until you close it with Escape.
- **Handovers stay findable.** The artifact rail keeps each agent's newest handover in reach, and Archive searches the saved ones after their pane has closed. Markdown review notes keep the words you reviewed.
- **An agent's sticky note wears the robot stamp on every skin**, so a note an agent wrote never passes for one of yours.
- **Uninstall keeps your records.** CONFIG › ADMIN exports them and removes old builds, and uninstall removes only files it can show Terminal Delight installed.
- **`terminal-delight restricted run`** runs a command that sees one directory, read-only system programs and its own temporary home, with no network, no other processes and no Terminal Delight controls.

### Carried from the 0.4.0 candidates

The terminal core is now rio-vt, from the Rio terminal: an 8 MB stream parses in 82 ms instead of 140, and programs that speak the Kitty graphics protocol draw pictures in the pane. Documents, pictures, PDFs, video and HTML briefs open in a floating square inside the terminal, and notes on a document go into the prompt of the agent beside it. Chalk, OPS and Intrusive join the looks, and a skin of your own is one TOML file. 🐞 writes a bug report that leaves your terminals' contents out. Off-limits panes are hidden from every other agent, model menus come from the agents you have installed, and an idle window uses less GPU memory. The [0.4.0 notes](v0.4.0.md) describe each.

## Upgrading from 0.3.0

Nothing you saved is renamed or moved. Sessions saved by 0.3.0 load, and the first window attaches to a session host 0.3.0 started.

- **Some keys changed.** Ctrl+Alt+R renames the highlighted left-bar row. Ctrl+W closes the document square on top, and Ctrl+Shift+W closes the tab. Shift+click on a file path reveals it in the file manager, and Ctrl+click opens it.
- **Terminal Delight now takes chords your shell or editor used to get:** Alt+1 to Alt+9 (pane marks; the 0.4.0 candidates' jump to a tab by its place is gone), Alt+0, Alt+O, Alt+Q, Alt+E, Alt+[, Alt+Shift with a letter you pin, Alt+L, Alt+A, Alt+G, Ctrl+= and Ctrl+-, Ctrl+Shift+M, and Ctrl+Up and Ctrl+Down in Claude Code and Codex panes.
- **Some looks change.** New windows open in Clean. The Gamba design is gone, and the Field design is now Tactical, keeping the palette and dials you picked.
- **Building from source?** Rust 1.99.1 is pinned in `rust-toolchain.toml`, and rustup fetches it on first use. Re-run `scripts/prepare-gpui.sh`.

The changelog's *Upgrading from 0.3.0* section has the full list.

## Upgrading from a 0.4.0 candidate

- **Restart your terminals once, when it suits you.** Two security fixes live in the session host, which keeps running the build it started with. Terminals opened before a window-only update stay on the old host until it next starts.
- **New Markdown saves move that document's notes to format 2.** Older notes stay readable, and older builds refuse to overwrite an upgraded store.
- **The first Dev build after this one installs at a cold start.** The fingerprint that decides whether a window and its terminals still agree used to read only part of each file it covers, and now reads all of it, so every build's fingerprint changes once.

## Security

- **The terminal core is rio-vt 0.5.29, which fixes RUSTSEC-2026-0430.** rio-vt 0.5.28 could be led by a picture command to delete a file outside its temporary directory, and to read shared memory past its end.
- **A program cannot make a pane keep picture uploads open without limit.** At most 16 unfinished uploads are kept at once.
- **No agent prompts another without a line a person drew**, and a copy of another agent can only read.
- A paste can no longer end bracketed paste early and type the rest into your shell, and HTML pages open with the network off unless you allow it.

## Known limits of this candidate

- Recorded handoffs to agents that are already running are not in 0.5.0. They stay on their own development branch.
- The multi-pane qualification of agent-to-agent asks and prompts is not complete. The candidate hold is where it is measured.
- The updater's **Restart window**, **Restart everything** and the cold-start install of a staged build have been tested in code but have not yet run on a real display.
- The Dev channel's check that a new build still reads its predecessor's terminals runs only on the development branch, and has not run yet. Until it does, every Dev update that touches the terminal core waits for a cold start.

## Install

Linux x86_64, one file:

```sh
curl -LO https://github.com/parker-brown-family/terminal-delight/releases/latest/download/terminal-delight-x86_64.AppImage
chmod +x terminal-delight-x86_64.AppImage
./terminal-delight-x86_64.AppImage
```

The download line fetches the newest stable release. A candidate, marked Pre-release, is never served by it; to try one, download the AppImage from its own release page. Every release attaches the AppImage's SHA-256 as `terminal-delight-x86_64.AppImage.sha256`.

PDFs need poppler, video and sound need libmpv, and HTML pages need Chromium. Each is optional; without it, the file opens in your desktop's own app.
