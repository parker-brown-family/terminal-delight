# Terminal Delight 0.5.3

Terminal Delight is a GPU-native terminal for Linux, written in Rust, for running many shells and coding agents in one window. 0.5.3 adds a front door: you write a sentence and an agent starts. A side panel shows what your agents changed, and Settings replaces CONFIG as one book.

TD-Host-Restart: recommended

## Highlights

- **A sentence starts an agent.** The composer (Ctrl+Shift+E, or ＋ on the INBOX) takes what you want done, then the project, harness, model, effort and machine as chips. It shows the line it will run. Enter takes you to the new agent; Ctrl+Enter starts it behind and leaves you on the composer. An agent can start with no project, in a folder of its own.
- **The left spine is an INBOX.** Agents are shelved by what they need from you, with LOOK AT ME first.
- **A side panel beside the panes** shows a task's changes, files and pull requests in tabs, without covering a terminal. Agents open what they made there, never over what you're reading, and a Markdown file there can be written in.
- **Settings is one book.** Ctrl+, or ⚙ opens it over the window, laid out like T3 Code. Panels open inside it. Code › Worktrees cleans up old worktrees with a review and a second press, and never removes one with changes or with someone working in it.
- **Briefs open faster and record reading time.** A never-seen HTML page opens in about half the time, and Copy map names what you scrolled past.
- **Agents running a `/loop` keep running.** An agent waiting on its own scheduled wakeup is no longer rested or put to sleep, so its next turn comes.
- **What you raise is what you type into.** The composer and a pane's design menu never open under Settings. A pane's rename box and a sticky note no longer share a caret. A drag the window never saw end no longer comes back on the next press.

This release skipped the usual seven-day candidate hold at the maintainer's call: 0.5.3-rc.1 had run as his daily window, on the same code, before it was promoted.

## Upgrading from 0.5.2

Update from ⚙ Settings › Updates, or run `terminal-delight update`. Nothing you saved is renamed or moved.

- **Restart once, the session host included.** The skills bridge for agents lives in the session host, and the host outlives its windows: with every window closed it keeps your terminals running for about twelve hours. So closing and reopening Terminal Delight is not enough. After updating, quit every window, end the host with `pkill -f '[t]erminal-delight.* serve --session'` (or restart the computer), then start Terminal Delight and open a new Bash terminal before starting an agent. Your tabs come back from the saved session and each agent is resumed; scrollback, and anything else that was running in a terminal, is not. Until then, a new shell starts cleanly without the bridge.
- **CONFIG is now Settings**, behind the same corner door. What CONFIG held is on its pages.

**On a build older than 0.5.0?** It has no updater. Move `~/.local/bin/terminal-delight` aside and run `curl -fsSL https://terminal-delight.brownfamilysports.com/install.sh | sh`.

## Known limits

- A Markdown page in the side panel is edited through its source: a click on the page jumps there, but you can't type into the rendered page itself yet. (#1414)
- An idle Claude that starts a turn on its own with no timer (a Monitor event, a session cron) can still be rested if the freeze lands in the instant before it says it is busy, and `CronCreate` crons are not read.
- A picture pasted into the composer does not reach an agent started on a far machine: it stays on this one. (#1440)
- Codex agents that share a folder don't all come back after the host restart: only the newest conversation in that folder reopens, and the other panes return as plain shells with a note. Before ending the host, quit each of those Codex agents with Ctrl+C; each prints its own `codex resume <id>` line to run afterwards. (#1447)
- Nothing in the app restarts the session host yet; the command above is the way for now. (#1446)
- The limits in the [0.5.2 notes](v0.5.2.md) still stand.
