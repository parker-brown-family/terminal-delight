# Terminal Delight 0.5.5

Terminal Delight is a GPU-native terminal for Linux, written in Rust, for running many shells and coding agents in one window. 0.5.5 opens GitHub issues and every link an agent hands back in the right bar, draws the minimal skin directly, and reads narrow agent panes correctly. The terminal core is rio-vt 0.5.32, as in 0.5.4.

## Highlights

- **The right bar opens more.** Alt+click a GitHub issue and it opens there. The + page lists and searches every link an agent put in a reply's Links table.
- **TERMINIMALIST draws directly,** with opaque surfaces and a focus rail. Settings › Appearance shows the skins as thumbnails.
- **Agents in narrow panes are read correctly.** A finished one is seen at rest, and a working one is not taken for idle, so the Threshing Floor hands work over at the right time.
- **A page an agent opens over its pane takes the reading keys** while that pane has the keyboard, as a page you open does. It never moves the keyboard off the pane you are in.
- **Gauges stay responsive.** A drag saves the session once, when it ends.
- **F2 to F12 reach programs,** with modifiers.

The [changelog](../../CHANGELOG.md) has the rest.

## Upgrading from 0.5.4

Update from ⚙ Settings › Updates, or run `terminal-delight update`.

- **Project folders** come from `roots` in `launch.toml`. With no list, Terminal Delight looks in `~/Work`, `~/work`, `~/src`, `~/code`, `~/projects`, `~/Projects`, `~/dev` and home.
- **Another machine reaches in over ssh only.** Two homes on one computer need `TD_FAR_DOOR_LOCAL=1` on the window being reached. An agent that runs `ssh localhost` is not stopped by this.

## Known limits

- A page that opens while you are typing into its own pane takes those letters. With a decision selected, `c` stamps CONCUR.
- Pictures cannot be sent to an agent on another machine.
- The limits in the [0.5.4 notes](v0.5.4.md) still stand.
