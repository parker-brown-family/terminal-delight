# Terminal Delight 0.5.2

Terminal Delight is a GPU-native terminal for Linux, written in Rust, for running many shells and coding agents in one window. 0.5.2 makes Super+C safe on Omarchy, lets you see your desktop through a terminal, and finishes the app's translations.

## Highlights

- **Super+C copies on a stock Omarchy.** Omarchy sends Super+C as Ctrl+C to any window it doesn't count as a terminal, and that interrupted the agent in the pane. Terminal Delight now tags its own windows as terminals, so Super+C copies and Super+V pastes with no setup.
- **See your desktop through a terminal.** GAUGES gains **opacity** under ACTIVE TERMINALS and INACTIVE TERMINALS. The field goes see-through while the letters stay solid, on the CRT too. Both start at 100%, and a fullscreen window stays solid.
- **Open briefs in the glow pane or the fullscreen reader.** GAUGES › FLOATING DOCUMENT gains a toggle. Fullscreen stays the default, the choice is saved for the window, and switching keeps your place and your notes.
- **The rest of the app follows your language.** The remaining controls and status messages are translated in all nine languages.
- **Scroll mode reaches Codex.** Alt+[ now moves the view in a Codex pane, where the arrows and paging keys had done nothing.
- **A pasted picture stays on its section.** When ↪ sends your notes to an agent, each picture stays with the section you pasted it on, and the notes bar counts the pictures that went.
- **Inactive brightness reaches the active pane.** At 100% an unfocused pane matches the focused one, text and glow included. The default look is unchanged.
- **TERMINIMALIST's relationship row reads as a sentence:** *+ Actor → Choose verb → Choose target*.

## Upgrading from 0.5.1

Update from ⚙ CONFIG › UPDATES, or run `terminal-delight update`. Nothing you saved is renamed or moved.

- **The Super+C line can go.** If you added `o.window("terminal-delight", { tag = "+terminal" })` to `hyprland.lua`, it is safe to delete or keep.

**On a build older than 0.5.0?** It has no updater. Move `~/.local/bin/terminal-delight` aside and run `curl -fsSL https://terminal-delight.brownfamilysports.com/install.sh | sh`.

## Known limits

- A window's tag lands about a second after it opens, so a Super+C in that first second still arrives as Ctrl+C.
- A low inactive opacity doesn't go fully clear while inactive brightness is below 100%, because the brightness veil still darkens the field. (#1361)
- Some ANSI colours sit well under default text's contrast on a few palettes, about 1.4:1 at worst on Miasma. (#1360)
- A window saved on 0.5.0's Clean look reads at 2.8:1 on Tokyo Night. (#1344)
- The limits in the [0.5.1 notes](v0.5.1.md) still stand.
