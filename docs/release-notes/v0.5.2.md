# Terminal Delight 0.5.2

Terminal Delight is a GPU-native terminal for Linux, written in Rust, for running many shells and coding agents in one window. 0.5.2 makes Super+C safe on Omarchy, lets you see your desktop through a terminal, and finishes the app's translations.

## Highlights

- **Super+C copies, with nothing to set up.** Omarchy turns Super+C into Ctrl+C for any window it doesn't count as a terminal, so on a stock install the press interrupted the agent in the pane. Terminal Delight now marks its own windows as terminals, so Super+C copies and Super+V pastes.
- **See your desktop through a terminal.** ACTIVE TERMINALS and INACTIVE TERMINALS in GAUGES each gain an **opacity** slider. Below 100% the field goes see-through to the desktop, on the tube too, while the letters, cursor and bezel stay solid.
- **Briefs open where you like them.** FLOATING DOCUMENT in GAUGES gains a toggle between **reader mode**, the fullscreen default, and the **glow pane**. Switching an open brief keeps your place and your notes.
- **The rest of the app is translated.** The remaining controls and status messages follow your language in all nine.
- **An unfocused pane can match the one you're in.** Above its default 78%, inactive brightness also lifts text and letter glow, so at 100% the two panes look the same.
- **Scroll mode works in Codex.** Alt+[ opened it, but the arrows and paging keys did nothing.
- **A pasted picture stays on its section** when ↪ sends your notes to an agent, and the notes bar counts how many went.
- **TERMINIMALIST's relationship row reads as a sentence:** *+ Actor → Choose verb → Choose target*.

## Upgrading from 0.5.1

Update from ⚙ CONFIG › UPDATES, or run `terminal-delight update`. Nothing you saved is renamed or moved.

- **Your windows look the same.** Opacity starts at 100%, and briefs open fullscreen until you choose otherwise.
- **The Super+C line can go.** If you added `o.window("terminal-delight", { tag = "+terminal" })` to `hyprland.lua`, delete it or keep it. It does no harm either way.

**On a build older than 0.5.0?** It has no updater. Move `~/.local/bin/terminal-delight` aside and run `curl -fsSL https://terminal-delight.brownfamilysports.com/install.sh | sh`.

## Known limits

- A window's tag lands about a second after it opens, so a Super+C in that first second still arrives as Ctrl+C.
- A low inactive opacity doesn't go fully clear while inactive brightness is below 100%, because the brightness veil still darkens the field. (#1361)
- Some ANSI colours sit well under default text's contrast on a few palettes, about 1.4:1 at worst on Miasma. (#1360)
- A window saved on 0.5.0's Clean look reads at 2.8:1 on Tokyo Night. (#1344)
- The limits in the [0.5.1 notes](v0.5.1.md) still stand.
