# Terminal Delight 0.5.1

Terminal Delight is a GPU-native terminal for Linux, written in Rust, for running many shells and coding agents in one window. 0.5.1 changes what a new window looks like, and makes one line enough to install it.

## Highlights

- **A new window opens in Deco, on the tube.** The Deco design and the Deco skin together, following your Omarchy theme, with the cursor tracer on. Default text clears 4.5:1 in every design, skin and palette, and a test holds that. A window you already have keeps its settings.
- **Programs wear your Omarchy theme.** A window following Omarchy paints the sixteen colours programs use from the theme. `ls` folders read as they do in the desktop's other terminals, where xterm's dark blue had measured 1.2:1 to 1.7:1 on dark themes.
- **One line installs it.** `curl -fsSL https://terminal-delight.brownfamilysports.com/install.sh | sh` puts the AppImage at `~/.local/bin/terminal-delight` with its launcher entry and icons, after checking it against the published checksum.
- **The floating document has its own gauges.** GAUGES gains a FLOATING DOCUMENT section: brightness, contrast, see-through and glow, per pane. They work the same on a page, a picture, a PDF or Markdown.
- **Agents sleep after an hour of rest,** down from two, and the rest and sleep sliders no longer overlap.
- **The Floor reads better.** An org can be deleted from a red button in the header, a two-way relationship is one line with an arrow at each end, and TERMINIMALIST's zoom buttons say zoom.
- **A window in a plain folder is not a finding.** The Git chip says *No new findings* until a repository is in view.
- **`ctl` no longer cuts off a busy window.** Only a refused connection counts as stale now.
- **A 529 on screen is not an API error.** Any agent showing those digits was marked as errored, and a prompt to another agent could be refused because of a process id. The real message still reads as an error.

## Upgrading from 0.5.0

Update from ⚙ CONFIG › UPDATES, or run `terminal-delight update`. Nothing you saved is renamed or moved.

- **A window that follows Omarchy changes colour.** Programs in it take the theme's sixteen colours from the first start on 0.5.1. A window with a palette you picked yourself is unchanged.
- **Your look stays.** The Deco defaults are for new windows only.
- **Agents sleep sooner** unless you moved the sleep slider yourself.

**On a build older than 0.5.0?** It has no updater. Move `~/.local/bin/terminal-delight` aside and run the install line above.

## Known limits

- Bright black departs from the theme on purpose. It sits 60% of the way from the background to the text, because several themes put it too close to the background to read through the tube.
- Light themes lose contrast on `ls` folders, because the theme's own blue is now the colour used. Rose Pine's measure 2.4:1.
- The limits listed in the [0.5.0 notes](v0.5.0.md) still stand: recorded handoffs to running agents are not in, the multi-pane qualification of asks and prompts continues, the updater's restart paths have not run on a real display, and the Dev channel's check of the terminal core has not yet attested a change.
