# Slices: GUI in the TUI — documents open in the pane

_Gate 4. One line per slice, in build order. Each ends in a working, testable state and is shown working before the next starts. Each slice is one pull request to `main` (merge on green); deploys are proposed after slices 2, 4, 6 and 8, where the feature is usable a step further._

1. **Tracer bullet — Alt+click a PNG, it floats, Esc closes it.** The classifier (all kinds recognised; only images drawn, the others say "not yet"), the Alt branch of the click table, a fixed-position floating square with the hyperglow, the image backend's fit view, the `Float` key layer for Escape, and the texture given back on close — proved by counting atlas textures across a hundred open-and-close cycles.
2. **The floating square, whole.** Drag by the strip (and release outside the pane), ✕ and ↗ desktop, hit-testing through the bent glass, the Alt chip saying "open here" or "copy", the full click table (Shift+click reveals, Ctrl+click unchanged), the right-click menu's new items and Copy link, image zoom and pan, the help modal and the ten languages.
3. **Markdown.** The lifted renderer with TD's palette, clickable links routed back through the router, local images, manual scroll, the file watcher keeping your place on a reload, and the workbench's Markdown cards drawn by the same renderer.
4. **The split.** Ctrl+Alt+click opens a document pane beside the one you clicked, focus staying where you were; a tab already showing the file focuses it; at four panes the float opens instead and says why; the float's "click to split" and a second Alt+click promote it; alt+k moves between a document and its shell; a document pane swallows typing; `ctl bench off` leaves it alone.
5. **The layout remembers.** A split showing a document comes back after a restart with its place kept; a missing file keeps its pane and says it cannot read the file; a replica repair keeps the document and the float.
6. **HTML, read-only.** The page-engine trait, TD's DevTools client over a pipe, the snapshot engine (one Chromium, a fresh profile, the network blocked, idle shutdown), tiles captured viewport-first with at most five on the GPU, the page cache, links and the brief's own modal buttons routed, each modal rendered on demand, and a missing Chromium handing the file to the desktop with a sentence.
7. **Notes, read.** Badges and counts from the brief's notes and concur blocks, note buttons where the browser puts them, the note box listing what is saved, concur stamps at the browser's angle, and copy map — held to the shared fixtures, which land in agent-skills first.
8. **Notes, write.** Add and delete notes, concur and unconcur, save into the file (fresh read, deltas, three splices, verify, backup ring, atomic rename, read-back), every refusal said in plain words, changes on disk while a brief is open, and the measurement that a saved note moves no anchor.
9. **Size answers.** The host answers `CSI 14 t` from live geometry (closes #718), a replica stops forwarding the question, a window-owned pane answers it, the PTY is told device pixels, and `CSI 16 t` is answered from the host's tee. Independent of slices 1–8; it can land at any point, or in parallel.
10. **Guards.** The fixture drift watch and sync script, a declared format version checked by TD's writer, the third-party licences, and the plan's status file closed with the difficulty the work turned out to be.
