Terminal graphics protocols

Research date 2026-09-24. Scope: what Terminal Delight (TD) itself must implement so that programs running inside a TD pane — mpv --vo=kitty, yazi, chafa, timg, presenterm, kitten icat, ratatui-image apps — can put real pixels on screen.

Summary — the facts that decide feasibility

1. Nothing a graphics client sends reaches TD's emulator today. vte 0.15 routes ESC _ (APC), ESC ^ (PM) and ESC X (SOS) into one state whose bytes go to anywhere(), which only watches for CAN, SUB and ESC; every other byte is discarded.

2. So every client's detection fails, quietly. Clients detect Kitty by sending a=q followed by DA1…

yellow = proposal, not decided: focus staying on the agent, "bring the existing pane forward", the DOC label and its colour, and "◳ float" to send the split back to a floating square. When the tab already has four panes (TD's cap), the proposal is that Ctrl+Alt+click opens the floating square instead and says why.
