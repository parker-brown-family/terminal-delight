# Reading a workbench card

A person reviewing twenty agents can have only 600 pixels for the pane with the decision. At that width the default card invites approval while hiding the question and both costs.

Every opened card should identify the work and place its actions where the reader can find them again. Keep the full decision and patch evidence reachable at both widths. The compact response feed should preserve the distinction between the latest reply and the one the reader selected. The Overview stays scoped to its pane.

Success means that all seven named kinds expose their content and supported actions by keyboard at both pane widths. An unfamiliar kind should retain its original name and payload. The before and after photos use the same inputs and skins. A separate Blueprint set covers Settings, the Threshing Floor, help and the workbench.
