# Validation: sticky Omarchy inheritance

The actual background watcher was run against temporary Omarchy state directories. It followed a second and third theme change without changing the saved choice, detected a replacement directory with its original timestamp, retained the last good colours through malformed and absent files, and recovered when a valid file returned. A pane following outer received the new colours; a pinned pane stayed independent until pass down. INVERT composed with the inherited colours. Explicit off and an undeclared preference remained distinct through serialization.
