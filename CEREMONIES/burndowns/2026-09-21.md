## 5-minute monologue
Where we were on Monday: the workbench composer was a mirror of the agent's own line editor. Every key went down the pseudoterminal first and the local copy existed to draw a caret. That was elegant and it was the cause of every text-entry complaint of the week — ctrl+c ended a session, shift+enter emptied the box while the agent kept the draft, a click into a selection left two copies of one draft holding different strings, and a multi-question round was readable one screen at a time, zero of forty-four while pending.

What moved: Parker annotated the composer brief on Sunday morning and rejected all three placements of the boundary in favour of a fourth — decouple the workbench from the terminal view and put an API against the process. The Gate 1 pane measured the seam (124 `self.bench` references, fourteen pty-write sites) and, crucially, found that a `PreToolUse` hook on the question tool is handed the whole round before any picker paints. The DECOUPLE-ASYNC pane took Gates 2–4 while Parker was AFK, with one instruction: build it, write the decisions down. The keystone was measured before a line was written — an interactive Claude Code driven under a pseudoterminal, a hook returning `updatedInput` with an answers map, the picker never painting. Then the channel: files, not a wire, so the host (which only upgrades by dying) is untouched; a state machine with no window in it; every write a record before it is an act; the old keys road kept and journaled so the fallback is never silent.

What did not move, and why: the ownership move — `Bench` is still a field on the pane — is deliberately after the tenancy pane's conversation key lands, because two agents reshaping one struct in one afternoon is how a merge eats a day. Codex and Gemini are screen-only agents until someone drives their hooks. And Fieldcraft, the memory loop's closing step, has produced nothing for this project all week; every done ticket's deliverable sits in the kanban and nowhere a future agent reads at boot.

What the afternoon taught: the demo found the one case nobody predicted (a face flipped mid-wait released the hook as "stale", and the record could not say why), the navigator pane found that a round arriving whole breaks a "newest arrival" rule written for questions arriving one at a time, and reading the sweep before wiring the beacon caught a marker file that would have been an `unclassified` card on every bench at one hertz. The hardening pass answered the first and the third with a spec bump to 0.2, twenty-two channel tests including one that drives the real adapter script end to end, and fourteen adapter tests.

Next week: the navigator lands; the ownership move follows the tenancy key; the relay for another device gets a brief before code (#632).
