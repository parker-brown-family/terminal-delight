What changed

The tube bent the page itself at first, and at the curve you asked for, the text came apart. The fix was already written down in the curved-glass lessons: bend a picture of the page, never the page.

So the page is drawn into a texture at twice the resolution and bent in a shader. Text stays whole, a click lands on whatever is drawn under the pointer, and the docs went live with it.

02

Bench

Not a terminal person? Flip any agent pane to its BENCH face and the agent's work is laid out as cards: what it said, what it wants you to decide, the files it made, and your own notes on them. You can follow an agent and steer it from here without reading its terminal.

04

Glass

The CRT is a real shader pass: barrel warp, scanlines, bloom and a rolling tracking band. A theme file sets how much of each you get, and a running terminal picks up the change as soon as you save. This page wears a cheaper copy, and both switches below are live.

06

Install

MIT, Linux only, on purpose. One AppImage runs on X11 and Wayland.

AppImage

One file, about 32 MB. Download it, mark it executable, run it. The guide covers what it needs from your system and where it keeps its settings.

Install guide → Changelog

From source

# deps (Ubuntu): Vulkan + build libs
bash scripts/setup-deps.sh
# the pinned Zed checkout + the td-crt-pass renderer patch
bash scripts/prepare-gpui.sh
# run it
cd app && cargo run
