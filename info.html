Bench

An agent pane has two faces. TERM is the terminal. BENCH lays the agent's work out as cards: what it said, what it wants you to decide, the files it made, and your own notes on them.

04

Glass

The CRT is a real shader pass: barrel warp, scanlines, bloom, and a tracking band that sweeps the screen every sixteen seconds. A theme file sets how much of it you get, and the running terminal picks up the change. This page wears a cheaper copy, and both switches below are live.

06

Install

MIT, Linux only, on purpose. One AppImage runs on X11 and Wayland.

AppImage

One file, about 32 MB. Download it, mark it executable, run it. The guide covers what it needs from your system and where it keeps its settings.

Install guide → Changelog

From source

# deps (Ubuntu): Vulkan + build libs
bash scripts/setup-deps.sh
# the pinned Zed checkout + the td-crt-pass renderer patch
bash scripts/prepare-gpui.sh
# run it
cd app && cargo run
